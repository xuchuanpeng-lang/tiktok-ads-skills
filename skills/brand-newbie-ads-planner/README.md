# Brand Newbie Ads Planner

Set up your first TikTok Brand Ads campaign according to Best Practice. Choose Traffic, Reach or Video Views, prepare budgets, targeting, creatives and schedules, then confirm the concrete plan before creation.

## Install

Ask an assistant that supports GitHub skill installation:

```text
Install brand-newbie-ads-planner from:
https://github.com/xuchuanpeng-lang/tiktok-ads-skills/tree/main/skills/brand-newbie-ads-planner

Install the complete directory, including SKILL.md, agents and references, with the bundled country-to-region CSV.
```

## Connect TikTok for Business

The skill checks TT4B MCP connection, authorization and account access before account operations. If needed, follow the [official connection guide](https://business-api.tiktok.com/portal/docs/how-to-connect-to-tiktok-for-business-mcp-server/v1.3) to configure MCP in your agent and authorize access.

## Start

```text
Use $brand-newbie-ads-planner to set up my first TikTok Brand Ads campaign according to Best Practice. Recommend the objective, budget, targeting, creatives and schedule, and show the concrete plan before making changes.
```

Best Practice region comes from the advertising account's registered country read through MCP, mapped to NA, EUI, METAP, LATAM or APAC. Delivery targeting follows the advertiser's business goals and confirmed countries. Replies default to English unless another language is explicitly requested.

2026 Q4 incentive guidance is subject to the program's dates, conditions and verified eligibility. Installing this skill does not grant MCP access or authorize ad delivery.
